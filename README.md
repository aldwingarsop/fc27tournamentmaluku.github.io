# 🏆 Tournament Hub - Database & Portal Turnamen (Online/Offline)

Platform berbasis web untuk mengelola, menyimpan, dan menampilkan database turnamen game atau olahraga, baik yang diselenggarakan secara **Online** maupun **Offline**. Platform ini memungkinkan penyelenggara mempublikasikan turnamen mereka dan memudahkan peserta untuk melihat informasi serta mengakses pendaftaran.

## 🚀 Fitur Utama
*   **Database Turnamen Terpusat:** Menyimpan data turnamen yang lalu, sedang berjalan, dan yang akan datang.
*   **Filter Online/Offline:** Memudahkan pengguna mencari turnamen berdasarkan tipe pelaksanaan atau lokasi.
*   **Akses Pendaftaran Mudah:** Menyediakan tombol aksi langsung menuju formulir pendaftaran atau link eksternal turnamen.
*   **Informasi Detail:** Menampilkan detail lengkap mulai dari tanggal, total hadiah (prizepool), slot tim, hingga regulasi.
*   **Desain Responsif:** Nyaman diakses melalui komputer maupun smartphone.

---

## 🛠️ Teknologi yang Digunakan
*   **Frontend:** HTML5, CSS3, JavaScript (atau sebutkan framework Anda seperti React / Vue / Vite jika ada)
*   **UI Framework:** Tailwind CSS / Bootstrap (opsional, sesuaikan dengan proyek Anda)
*   **Database/Backend:** (Sebutkan jika menggunakan Firebase, Supabase, Node.js, atau LocalStorage untuk prototype)
